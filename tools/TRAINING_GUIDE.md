# 模型训练指南（60怪物配置）

## 当前状态

- **怪物数量**: 60种（来自 `monster_greenvine.csv`）
- **场地特征**: 0个（已禁用）
- **模型输入维度**: 60维（left_counts）+ 60维（right_counts）
- **旧模型**: 77维（不兼容，需要重新训练）

## 数据收集阶段

### 1. 运行游戏收集真实数据

```bash
# 启动GUI，点击"自动获取数据"按钮
# 系统会自动在 data/YYYY_MM_DD__HH_MM_SS/arknights.csv 中保存数据
```

**数据格式说明**:
- 每行代表一场对战
- 前60列: 左侧怪物数量 (1L, 2L, ..., 60L)
- 后60列: 右侧怪物数量 (1R, 2R, ..., 60R)
- Result列: 胜负结果 (L/R)
- ImgPath列: 截图路径

### 2. 检查数据收集进度

```bash
# 查看当前数据量和分布情况
uv run python tools/prepare_training_data.py
```

这个脚本会：
- 合并所有 `data/*/arknights.csv` 文件
- 验证数据格式是否正确
- 统计每个怪物的出现频率
- 分析胜负分布
- 如果数据量>=50条，生成 `training_data_ready.csv`

### 3. （可选）生成测试数据

如果想先测试训练流程，可以生成合成数据：

```bash
# 生成200条合成数据用于测试
uv run python tools/generate_synthetic_data.py
```

**注意**: 合成数据仅用于测试流程，预测能力很差！

## 训练阶段

### 数据量建议

| 数据量 | 建议操作 |
|--------|----------|
| < 100条 | 继续收集数据 |
| 100-500条 | 可以尝试训练，但效果可能一般 |
| 500-1000条 | 推荐开始训练 |
| > 1000条 | 数据充足，可以训练高质量模型 |

### 执行训练

```bash
# 一键训练流程：
# 1. 聚合所有data目录下的CSV
# 2. 训练PyTorch模型
# 3. 转换为ONNX格式
# 4. 保存到 models/best_model_full.onnx
uv run python train_onnx.py
```

训练完成后会：
- 在 `models/` 目录生成新的 `.pth` 和 `.onnx` 文件
- 自动验证新模型是否可以正常推理
- 清理临时文件

### 验证新模型

训练完成后，重启GUI并测试：

1. 关闭并重新启动GUI程序
2. 点击"自动获取数据"
3. 观察日志，确认没有维度错误
4. 检查预测结果是否合理

## 常见问题

### Q1: 训练时提示"数据不足"
**A**: 继续运行游戏收集更多数据，至少需要50条以上才能训练。

### Q2: 训练后预测结果都是0.5
**A**: 这是正常的初期现象，随着数据量增加，模型会逐渐学习到有意义的模式。

### Q3: 想使用旧的77怪物配置
**A**: 将 `monster_greenvine.csv` 替换回包含77种怪物的版本，然后重新训练。

### Q4: 如何查看模型训练进度
**A**: 训练过程中会在控制台输出loss值和准确率，也可以在代码中添加更多的日志输出。

## 技术细节

### 模型架构
- 基于 Transformer 的 UnitAwareTransformer
- 输入: left_counts (60维), right_counts (60维)
- 输出: 胜率预测 (0-1之间)

### 训练参数
- 详见 `train.py`
- 默认使用交叉熵损失
- 自动选择最佳模型

### ONNX导出
- 导出为2输入格式（兼容 predict_onnx.py）
- 动态batch size支持
- Opset version: 20
