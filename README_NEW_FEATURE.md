# 立即开始使用新功能

## 快速操作指南

### 方法1: 一键自动收集+训练（推荐）

1. **打开GUI程序**
   ```bash
   uv run python main.py
   ```

2. **设置参数**
   - 训练时长: 输入 `2` (表示2小时)
   - 游戏模式: 选择 "单人"

3. **点击按钮**
   - 找到绿色按钮: **"🔄 从0开始收集数据并训练"**
   - 点击它

4. **确认开始**
   - 阅读弹出的确认对话框
   - 点击"是"

5. **等待完成**
   - 程序会自动运行游戏
   - 每局固定选左
   - 实时显示剩余时间
   - 到达时间后自动停止并开始训练

6. **完成！**
   - 训练成功后会弹出提示
   - 新模型自动加载
   - 可以开始使用预测功能了

---

### 方法2: 手动分步操作

如果你想更精细地控制：

#### 步骤1: 收集数据
- 点击 **"自动获取数据"** 按钮
- 可以选择投资策略
- 手动控制何时停止

#### 步骤2: 检查数据
```bash
uv run python tools/prepare_training_data.py
```

#### 步骤3: 训练模型
- 点击 **"🧠 训练ONNX模型"** 按钮
- 等待训练完成

## 常见问题

### Q: 我现在可以点击"自动获取数据"吗？
**A**: 可以！临时修复已经完成，60维输入会被自动填充到77维。虽然预测不太准确，但可以用来收集数据。

### Q: 需要收集多少数据？
**A**: 
- 最少: 50条（可以训练但效果一般）
- 推荐: 500条以上（效果较好）
- 理想: 1000条以上（高质量模型）

### Q: 训练需要多长时间？
**A**: 
- 数据收集: 取决于你设置的时长
- 模型训练: 通常5-30分钟（取决于数据量和CPU性能）

### Q: 如果中途想停止怎么办？
**A**: 
- 再次点击同一个按钮
- 或者直接关闭GUI窗口

### Q: 新模型预测不准怎么办？
**A**: 
- 这是正常的，继续收集更多数据
- 然后重新训练（点击"训练ONNX模型"）
- 数据越多，模型越准确
